# Workout Tracker App

A React workout tracker for Push Pull Legs training plan. All data is stored locally using localStorage. Responsive, dark-themed, and PWA-ready.

## Features
- Push/Pull/Legs workout split
- Exercise cards with GIFs, YouTube links, log weight button
- Log sets, reps, weight per exercise
- Progress dashboard with charts (Recharts)
- Workout history
- Export logs as JSON
- Mark exercises as completed
- Responsive, modern UI (TailwindCSS)
- Dark theme

## Folder Structure
- src/components
- src/pages
- src/data
- src/hooks
- src/utils
- src/charts

## Getting Started
1. Install dependencies:
	```bash
	npm install
	```
2. Start the app:
	```bash
	npm run dev
	```

## PWA Support
Add manifest and service worker for full PWA support (optional).
